Data Analyst Intermediate Task — Sales Dashboard

Project Overview
This project presents a sales performance dashboard created using Power BI.
The objective is to transform raw sales data into clear business insights that help understand company performance, customer behavior, and growth trends.

Tools Used
	•	SQLite Browser (data exploration)
	•	Microsoft Power BI (visualization & dashboard)
	•	GitHub (project submission)

Dashboard Features
The interactive dashboard includes:
	•	KPI Cards (Total Revenue, Total Orders, Average Sales)
	•	Monthly Sales Trend (Line Chart)
	•	Category-wise Sales Comparison
	•	Region-wise Performance
	•	Customer Segment Analysis

Filters (User Interaction)
Slicers were added so users can explore the dashboard dynamically:
	•	Year
	•	Category
	•	Region
	•	Customer Segment

Business Insights
An Insight Summary report is provided in non-technical language explaining:
	•	Sales growth pattern
	•	High performing regions
	•	Major customer segments
	•	Areas of improvement
The report is available inside the /reports folder.

Conclusion
The dashboard converts raw sales data into meaningful visual insights.
It helps management understand performance and supports better business decisions related to marketing, expansion, and customer retention.
