## Task 2 – SQL Analysis (SQLite)

In this task, the Superstore_US dataset was analyzed using DB Browser for SQLite.  
SQL queries were written to generate business insights using SQL operations such as GROUP BY, SUM, ORDER BY, LIMIT, and date functions.

### Key Analysis Performed
- Calculated total company revenue  
- Identified the highest-earning product category  
- Found the top 10 best-selling products  
- Determined the region contributing the most revenue  
- Analyzed monthly sales trends to understand seasonal demand

###Buisness-Style Insights
The analysis highlighted profitable categories, high-demand products, strongest regions, and monthly sales patterns.  
These insights can help in inventory management, marketing planning, and business decision-making.
