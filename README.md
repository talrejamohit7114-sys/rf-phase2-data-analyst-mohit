## Summary
This repository contains my Phase 2 intermediate tasks as a Data Analyst. It includes theoretical concepts, hands-on data analysis using Python, SQL-based business insights, and an interactive dashboard with clear non-technical insights. I have implemented the end-to-end data analysis lifecycle to transform raw business data into actionable insights through trend analysis and KPI tracking.
