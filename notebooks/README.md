# Superstore Sales Data Analysis

## Project Overview
This project performs Exploratory Data Analysis (EDA) on the Superstore dataset using Python (Pandas).

The objective is to clean the dataset, handle missing values, remove duplicates and understand the data before visualization.

---

## Technologies Used
- Python
- Pandas
- Jupyter Notebook
- VS Code
